# WebAppPractice_Man
 
A PHP web application built to practice and understand web application security and penetration testing concepts.
 
## Overview
 
This is a simple web application with user authentication features. It includes a registration system, login functionality, and user profiles. The project focuses on learning PHP, form handling, input validation, and web security best practices.
 
## Features
 
This application includes user registration functionality that allows users to create new accounts with validation. Users can authenticate themselves through a login system that uses session management to keep track of logged-in users. Once logged in, users can view their profile information. The application validates all inputs including names, emails, and passwords to ensure data integrity. Passwords are securely hashed using SHA-1 before being stored. Any validation errors are displayed to users in a clear format, and session management is used throughout to track authenticated users and maintain their login state.
